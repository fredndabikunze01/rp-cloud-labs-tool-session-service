# RP-Cloud Labs — Tool-Session Service

## Project Overview

RP-Cloud Labs is a platform proposed by Rwanda Polytechnic to provide students and lecturers with browser-based access to hosted learning tools without requiring local software installation.

The Tool-Session Service is responsible for processing student requests for learning tools, validating student accounts, checking available college software license capacity, and recording tool sessions.

## Objectives

- Enable students to request access to hosted learning tools.
- Validate student accounts before granting access.
- Check college license capacity before approving requests.
- Record and track tool sessions.
- Support consistent access to learning tools across different colleges.

## Scope

This project focuses on developing, testing, deploying, and maintaining the Tool-Session Service as part of RP-Cloud Labs.

## Technologies and Tools

- GitHub and GitHub Actions
- Docker
- Kubernetes
- Redis
- Apache Kafka
- Flyway
- A suitable backend framework and database

## Team Collaboration

Team members will work on separate feature branches. Changes will be submitted through pull requests and reviewed before merging into the main branch.

## Expected Outcome

A working Tool-Session Service that processes tool-session requests and checks license availability reliably.
